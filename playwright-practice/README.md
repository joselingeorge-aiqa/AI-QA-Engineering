# Playwright Practice

## Purpose
A hands-on workspace for practising browser automation using Playwright and TypeScript.

## Learning Objectives
- Understand Playwright project setup
- Write and execute browser tests
- Validate page behavior and UI elements
- Practise assertions and test organization
- Learn debugging and test reporting

## Setup
Document the required Node.js version, installation commands, and test execution commands for this project.
